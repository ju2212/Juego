# Proyecto PRISMA

Juego de aventura y supervivencia en 3D para jugar en el teléfono (en el navegador, en horizontal).
Transcurre en Tandil, en un futuro dañado por la IA. La primera zona es la fábrica PRISMA.

- **Diseño del juego:** [`docs/GDD.md`](docs/GDD.md)
- **Juego (prototipo):** [`game/index.html`](game/index.html), hecho con Babylon.js

## Estado
Prototipo 0.1: moverse y explorar la fábrica (joysticks táctiles, correr, saltar, rampa y pasarela, 5 celdas de energía).

## Controles
- **Teléfono:** joystick a la izquierda para moverte, arrastrar a la derecha para mirar, botones SALTAR y CORRER.
- **Computadora:** WASD o flechas, Shift para correr, Espacio para saltar, arrastrar el mouse para mirar.
- Agregá `#fps` al final de la dirección para ver los cuadros por segundo.
